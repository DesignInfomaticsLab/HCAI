# 04 · 디자인 시스템

첫 시안의 설계 의도와 규칙입니다. **여기 적힌 값을 바꾸면 사이트 전체가 한 번에 바뀝니다.**
피드백은 이 문서의 항목 번호를 짚어 주시면 정확하게 반영할 수 있습니다.

---

## 1. 설계 의도

기존 Cargo 사이트의 **다크 톤 · Pretendard · 블루 액센트**는 계승하되, 세 가지를 바꿨습니다.

| | 기존 (Cargo) | 새 사이트 |
|---|---|---|
| 구조 | 좌우 분할 패널, 클릭해서 열고 닫는 방식 | 목적별 페이지 + **연도순 인덱스** |
| 확장성 | 항목이 늘면 패널이 답답해짐 | 항목이 100개가 되어도 같은 리듬으로 쌓임 |
| 데스크탑/모바일 | 별도 페이지를 각각 관리 | 하나의 반응형 레이아웃 |

핵심 개념은 **"아카이브는 목록이다"** 입니다.
연구센터의 자산은 화려한 인터랙션이 아니라 *무엇을 언제 했는가*의 축적이므로,
그 목록이 가장 읽기 좋은 형태가 되도록 나머지를 절제했습니다.

**세 가지 원칙**

1. **면이 아니라 선으로 나눈다** — 박스·그림자 대신 1px 헤어라인. 정보가 늘어도 시각적 소음이 늘지 않습니다.
2. **날짜가 항상 왼쪽 첫 칸에 있다** — 어떤 목록이든 시선의 출발점이 같습니다. 이것이 아카이브의 척추입니다.
3. **한글이 주인이다** — 영문 폰트에 한글을 끼워 넣은 조판이 아니라, Pretendard 기준으로 자간·행간을 잡았습니다.

## 2. 색 (`style.css` 의 `:root`)

```css
--bg:          #0E0E10;   /* 배경. 순수 검정(#000)보다 살짝 밝아 눈이 덜 피로 */
--bg-elev:     #16161A;   /* 카드·호버 면 */
--bg-elev-2:   #1D1D22;   /* 이미지 자리, 한 단계 더 위 */

--fg:          rgba(255,255,255,.92);  /* 제목 */
--fg-mid:      rgba(255,255,255,.60);  /* 본문 */
--fg-dim:      rgba(255,255,255,.38);  /* 메타 정보, 라벨 */
--fg-faint:    rgba(255,255,255,.22);  /* 화살표 등 장식 */

--line:        rgba(255,255,255,.10);  /* 기본 구분선 */
--line-strong: rgba(255,255,255,.22);  /* 섹션 구분선 */

--accent:      #2F7BFF;   /* 기존 #0074FF 를 다크 배경용으로 살짝 밝힘 */
--accent-hi:   #6BA4FF;   /* 링크 hover */
```

**흰색을 4단계로 나눈 것이 이 디자인의 핵심**입니다.
글자 크기를 키우는 대신 **밝기로 위계를 만들면** 화면이 조용해지고 정보 밀도를 높일 수 있습니다.

> 🎨 **피드백 포인트**: 액센트 색을 기존 `#0074FF` 그대로 쓸지, 아예 다른 색(예: 연구센터 상징색)으로 갈지.
> 배경을 완전한 검정 `#000` 으로 할지, 지금처럼 살짝 든 회색으로 둘지.

## 3. 타이포그래피

- **본문/제목**: Pretendard Variable (CDN)
- **메타·라벨·연도**: 시스템 모노스페이스 — *데이터·기록물*의 인상을 주기 위한 의도적 선택입니다

| 용도 | 토큰 | 크기 |
|---|---|---|
| 홈 대문 | `--fs-display` | 44 → 96px (화면 폭에 따라 유동) |
| 페이지 제목 | `--fs-h1` | 32 → 52px |
| 섹션 제목 | `--fs-h2` | 24 → 34px |
| 카드·목록 제목 | `--fs-h3` | 18 → 22px |
| 본문 | `--fs-body` | 16px / 행간 1.72 |
| 메타 | `--fs-xs` | 12px / 자간 +0.16em |

**한글 조판 규칙 두 가지**

- `word-break: keep-all` — 단어 중간에서 줄바꿈되지 않습니다 (한글 가독성에 결정적)
- 제목 자간 `-0.025em` — Pretendard는 기본 자간이 넉넉해서 큰 제목은 살짝 조여야 단단해 보입니다

> 🎨 **피드백 포인트**: 대문 글자가 너무 큰지/작은지. 모노스페이스 라벨이 취향에 맞는지
> (원하시면 라벨도 Pretendard로 통일 가능합니다).

## 4. 컴포넌트

### ① 인덱스 행 `.index__row` — 이 사이트의 주인공

```
2025.04 – 2028.12 │ 디자이너 중심의 AI 디자인 생성 파이프라인 개발  │ [진행중] KEIT │ →
                  │ 디자이너의 의도를 반영한 멀티모달 3D 생성…       │               │
```

- 4열: **날짜 · 제목+요약 · 메타 · 화살표**
- 마우스를 올리면 행 전체 배경이 미세하게 밝아지고 화살표가 오른쪽으로 4px 움직입니다
- 모바일에서는 자동으로 3줄 세로 배치로 접힙니다
- 연구·활동·성과·아카이브 **모든 목록이 이 하나의 규칙**을 씁니다

### ② 인물 카드 `.person`

- 사진은 **기본 흑백**, 마우스를 올리면 컬러로 — 여러 사람의 사진 톤이 제각각이어도 그리드가 정돈되어 보입니다
- 사진이 없으면 이름 이니셜이 자동으로 그려집니다 (빈칸이 생기지 않음)
- 연구소장만 가로형 큰 카드, 나머지는 4열 그리드

### ③ 칩 필터 `.chip`

- 활동 페이지의 `전체 / 뉴스 / 세미나 / 워크샵…` 버튼
- **분류를 `activities.json` 에 추가하면 버튼이 자동 생성**됩니다 — 코드 수정 불필요

### ④ 대문 배경 격자

- 96px 간격의 1px 격자에 방사형 마스크를 씌워 오른쪽 위로 갈수록 흐려집니다
- 설계도·좌표계의 은유이며, 이미지 없이도 첫 화면이 비어 보이지 않게 하는 장치입니다

> 🎨 **피드백 포인트**: 격자 배경이 과한지. 첫 화면에 큰 이미지나 영상을 넣고 싶은지.

## 5. 반응형 기준점

| 폭 | 변화 |
|---|---|
| ~ 720px | 헤더의 센터 전체 이름 숨김 (HCAI 마크만) |
| ~ 860px | 인덱스 행이 세로 3줄로 접힘 / 메뉴가 햄버거로 전환 |
| ~ 900px | 2단 `.split` 레이아웃이 1단으로 |

여백 `--pad-x` 와 최대폭 `--max-w: 1560px` 만 조절하면 전체 밀도가 한 번에 바뀝니다.

---

## 6. 접근성 · 기타

- 모든 대화형 요소에 `:focus-visible` 파란 외곽선 — 키보드 사용자 대응
- `Tab` 을 누르면 맨 앞에 "본문으로 건너뛰기" 링크가 나타납니다
- `prefers-reduced-motion` 을 켠 사용자에게는 모든 애니메이션이 꺼집니다
- 인쇄(`Ctrl+P`) 시 헤더·필터가 사라지고 흰 배경으로 전환됩니다
