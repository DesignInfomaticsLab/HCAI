# 03 · 도메인 연결

배포만 하면 사이트 주소는 `https://hcai-hanyang.github.io/` 입니다.
여기에 원하는 주소를 붙이는 방법입니다.

---

## 먼저 결정할 것 — 두 가지 길이 있습니다

### 길 A · 기존 `aidesign.hanyang.ac.kr` 을 그대로 쓴다 (비용 0원, 권장)

지금 이 주소는 학교가 발급한 `hanyang.ac.kr` 의 하위 도메인이고, 현재는 Cargo 서버를 가리키고 있습니다.
**가리키는 곳만 GitHub으로 바꾸면** 주소는 그대로 두고 내용만 새 사이트로 바뀝니다.

- **장점**: 무료, 갱신 걱정 없음, `.ac.kr` 이라 학술 기관 신뢰도가 높음, 기존 링크·논문 각주가 안 깨짐
- **단점**: 변경할 때마다 학교 정보통신처에 요청해야 함 (즉시 처리 안 됨)
- **방법**: 정보통신처에 아래처럼 요청합니다.

  > `aidesign.hanyang.ac.kr` 의 CNAME 레코드를 `hcai-hanyang.github.io` 로 변경 요청드립니다.
  > (기존 Cargo 대상 레코드는 삭제 부탁드립니다.)

### 길 B · 독립 도메인을 새로 산다

- **장점**: 우리가 직접 즉시 관리 가능, 이름을 자유롭게 지을 수 있음, 학교를 옮겨도 유지
- **단점**: 연 1~3만 원, **갱신을 놓치면 사이트가 사라짐**

> **가장 좋은 조합**: 길 A와 길 B를 **둘 다** 하는 것입니다.
> 독립 도메인을 대표 주소로 쓰고, `aidesign.hanyang.ac.kr` 도 같은 곳을 가리키게 두면 양쪽 다 열립니다.

---

## 도메인 사기 (길 B)

### 이름 후보

| 후보 | 특징 |
|---|---|
| `hcai.kr` / `hcaid.kr` | 짧고 한국 기관임이 분명. `.kr` 은 국내 검색·인지도에 유리 |
| `hcai-design.org` | `.org` 는 비영리·연구기관 인상이 강함 |
| `hcaidesign.com` | 가장 무난하고 사람들이 잘 외움 |
| `hcai.design` | 디자인 연구센터라는 정체성이 드러남. 다만 연 5만 원 내외로 비싸고, 사람들이 `.com` 으로 잘못 치는 일이 잦음 |

> 실무 조언: **짧고, 받아 적기 쉽고, `.com` 또는 `.kr`**. 하이픈은 되도록 피하세요(구두로 알려주기 어렵습니다).
> 결정 전 [whois.kr](https://whois.kr) 이나 등록업체 검색창에서 사용 가능 여부를 확인하세요.

### 어디서 사는가

| 업체 | 추천 상황 |
|---|---|
| **가비아 / 후이즈** | `.kr` 도메인, 한국어 고객센터, 세금계산서 발행이 필요한 대학 회계 처리에 유리 → **연구비 정산이 필요하면 여기** |
| **Cloudflare Registrar** | `.com`, `.org` 를 **원가로** 판매(마진 0). 갱신비가 오르지 않아 장기적으로 가장 저렴. 단, 영문 결제이고 세금계산서 처리가 번거로움 |
| **Namecheap** | 중간 정도. 첫해 할인 후 갱신비가 오르는 경우가 많으니 갱신가를 꼭 확인 |

**가격은 대략 연 1.5~3만 원 수준**(TLD와 업체에 따라 다름)이니 결제 전 갱신가를 확인하세요.

### ⚠️ 구입할 때 반드시 지킬 것

1. **연구실 공용 계정 + 공용 이메일로 가입하세요.** 개인 이메일로 사면 졸업과 함께 도메인이 증발합니다.
2. **자동 갱신(Auto-renew)을 켜세요.** 그리고 결제 카드 유효기간을 캘린더에 등록하세요.
   → 홈페이지가 사라지는 사고의 90%는 "도메인 갱신 실패"입니다.
3. **개인정보 보호(WHOIS Privacy)** 를 켜세요. 대부분 무료입니다.

## DNS 설정하기

도메인을 산 뒤, 등록업체의 **DNS 관리 / 네임서버 설정** 화면에서 아래 레코드를 넣습니다.

### 경우 1 · `www.hcaidesign.com` 처럼 앞에 뭔가 붙는 주소

**CNAME 하나면 끝입니다.**

| 타입 | 호스트 | 값 |
|---|---|---|
| CNAME | `www` | `hcai-hanyang.github.io` |

### 경우 2 · `hcaidesign.com` 처럼 앞에 아무것도 없는 주소 (apex 도메인)

CNAME을 쓸 수 없어서 **A 레코드 4개**를 넣습니다. (IPv6까지 하려면 AAAA 4개 추가)

| 타입 | 호스트 | 값 |
|---|---|---|
| A | `@` | `185.199.108.153` |
| A | `@` | `185.199.109.153` |
| A | `@` | `185.199.110.153` |
| A | `@` | `185.199.111.153` |
| AAAA | `@` | `2606:50c0:8000::153` |
| AAAA | `@` | `2606:50c0:8001::153` |
| AAAA | `@` | `2606:50c0:8002::153` |
| AAAA | `@` | `2606:50c0:8003::153` |

> 이 IP 주소는 GitHub이 공식 안내하는 값입니다. 설정 전 [GitHub 공식 문서](https://docs.github.com/pages/configuring-a-custom-domain-for-your-github-pages-site)에서 최신 값인지 한 번 확인하는 것이 안전합니다.

> **`@` 는 "도메인 그 자체"를 뜻하는 기호**입니다. 업체에 따라 빈칸으로 두거나 도메인 전체를 적기도 합니다.

**권장 구성**: apex(`hcaidesign.com`)를 대표로 쓰고, `www` 는 CNAME으로 두면 둘 다 열립니다.

## GitHub에 도메인 등록하기

1. 저장소 → **Settings → Pages**
2. **Custom domain** 칸에 도메인 입력 (예: `hcaidesign.com`) → **Save**
   - 저장소 루트에 `CNAME` 파일이 자동 생성됩니다. **지우지 마세요.**
3. DNS 검사가 통과할 때까지 기다립니다 (보통 10분~수 시간, 드물게 24시간)
4. 통과되면 **☑ Enforce HTTPS** 를 체크합니다 — 무료 인증서가 자동 발급·갱신됩니다

> ⏳ **DNS 전파에는 시간이 걸립니다.** 설정 직후 안 열린다고 계속 값을 바꾸면 오히려 더 오래 걸립니다.
> 최소 30분은 기다린 뒤 [dnschecker.org](https://dnschecker.org) 로 전파 상태를 확인하세요.

## 전환 체크리스트

기존 Cargo 사이트에서 갈아탈 때 순서:

- [ ] 1. GitHub Pages로 새 사이트 배포 → `hcai-hanyang.github.io` 에서 정상 동작 확인
- [ ] 2. 모든 페이지·모바일·KO/EN 전환을 **실제로 눌러 보며** 점검
- [ ] 3. Cargo 사이트의 사진·문서 중 필요한 것을 모두 내려받아 `assets/img/` 로 옮겼는지 확인
- [ ] 4. 도메인 DNS를 GitHub으로 변경 (또는 학교에 CNAME 변경 요청)
- [ ] 5. 새 주소로 정상 접속 + HTTPS 자물쇠 확인
- [ ] 5-1. **`index.html` 의 `og:image` 를 절대 주소로 바꾸기**
      카카오톡·슬랙 등에 링크를 붙였을 때 미리보기 이미지가 뜨게 하려면
      상대 경로가 아니라 전체 주소여야 합니다.
      ```html
      <meta property="og:image" content="https://내도메인/assets/img/og.png">
      <meta property="og:url"   content="https://내도메인/">
      ```
- [ ] 6. **최소 한 달은 Cargo 구독을 유지**하다가 문제가 없으면 해지
- [ ] 7. Google Search Console에 새 사이트 등록 (검색 노출용)

## 자주 겪는 문제

| 증상 | 원인 / 해결 |
|---|---|
| "Domain does not resolve to the GitHub Pages server" | DNS가 아직 전파되지 않았거나 레코드 오타. 30분 기다린 뒤 재확인 |
| HTTPS 체크박스가 회색으로 비활성 | 인증서 발급 중입니다. 최대 24시간 기다리면 됩니다 |
| 도메인은 열리는데 CSS가 깨짐 | 저장소 이름이 `<조직명>.github.io` 가 아닌 경우 발생. 저장소 이름을 바꾸거나 도메인 연결로 해결됩니다 |
| push했는데 사이트가 그대로 | 저장소 **Actions** 탭에서 배포 상태 확인. 브라우저 강력 새로고침 `Ctrl+Shift+R` |
| 도메인 만료 안내 메일이 왔다 | **즉시 갱신하세요.** 만료 후 일정 기간이 지나면 제3자가 선점할 수 있습니다 |
