# 05 · 연구원 정보 수집 양식

홈페이지 구성원 페이지에 넣을 정보를 연구원들에게 받을 때 쓰는 양식입니다.

**쓰는 법**
1. 아래 [배포용 양식](#배포용-양식-이-부분만-복사해서-보내세요)을 그대로 복사해 단톡방·메일로 보냅니다
2. 각자 채워서 회신 + 사진 파일 첨부
3. 모인 답변을 그대로 저에게(또는 담당자에게) 전달하면 `content/people.json` 에 반영합니다

> 💡 답변을 **원문 그대로** 모아 두세요. 정리하거나 요약하지 않아도 됩니다.
> 형식이 조금 흐트러져도 반영할 수 있지만, 항목 이름(`이름:`, `영문 이름:` …)만은 지워지지 않게 해 주세요.

## 받은 정보가 홈페이지 어디에 들어가나

`content/people.json` 의 한 항목이 됩니다.

```json
{
  "id": "hong-gildong",
  "group": "member",
  "name":        { "ko": "홍길동", "en": "Gildong Hong" },
  "role":        { "ko": "석사과정", "en": "Master's Student" },
  "affiliation": { "ko": "한양대학교 실내건축디자인학과", "en": "Dept. of Interior Architecture Design, Hanyang University" },
  "email":       "gildong@hanyang.ac.kr",
  "keywords":    ["Generative Design", "Spatial Experience", "Design Cognition"],
  "bio":         { "ko": "생성형 AI가 …", "en": "I study how …" },
  "photo":       "assets/img/people/hong-gildong.jpg",
  "links": [
    { "label": "Web",     "url": "https://gildonghong.com" },
    { "label": "Scholar", "url": "https://scholar.google.com/citations?user=xxxx" }
  ],
  "since": "2025"
}
```

| 양식 항목 | JSON 필드 | 화면에서 |
|---|---|---|
| 이름(국문) / 이름(영문) | `name.ko` / `name.en` | 카드 제목 (KO/EN 전환) |
| 과정·직함 | `role` | 파란 라벨 |
| 소속 | `affiliation` | 회색 두 줄 |
| 연구 관심사 | `bio` | 소속 아래 문장 |
| 키워드 | `keywords` | 태그 칩 |
| 링크 | `links` | 카드 하단 링크 |
| 사진 | `photo` | 3:4 흑백 사진 (hover 시 컬러) |
| 합류 연도 | `since` | (현재 미표시, 정렬·이력 관리용) |

`id` 는 `성-이름` 형태의 영문 소문자로 담당자가 붙입니다.
사진 파일명도 `id` 와 같게 맞춥니다 — 나중에 누구 사진인지 바로 알 수 있습니다.

## 담당자 참고

- **졸업하면 항목을 지우지 마세요.** `"group"` 값만 `"alumni"` 로 바꾸면 졸업생 섹션으로 내려갑니다.
  아카이브의 목적은 지나간 사람도 남기는 것입니다.
- 영문 이름은 **랩 사이트(designai.hanyang.ac.kr)와 논문 표기를 우선**으로 맞춥니다.
  본인 확인 없이 로마자 표기를 추정하면 논문 검색에서 다른 사람이 됩니다.
- 사진 용량은 장당 **200KB 이하**로. 원본을 그대로 올리면 저장소가 금방 무거워집니다.
